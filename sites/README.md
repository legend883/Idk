# Client demo sites

Free redesign demos built to pitch Atlanta outdoor-living companies. Each folder is a complete site.
To preview, open its `index.html`. To put one online for free, drag the folder onto https://app.netlify.com/drop.
Each folder's README lists the photo file names and the facts to confirm with the client.

| Folder | Business | Specialty | Brand colors used |
|---|---|---|---|
| arnold-masonry | Arnold Masonry & Landscape | Masonry, outdoor kitchens, fireplaces | Charcoal, leaf green, slate blue |
| atlanta-porch-and-patio | Atlanta Porch & Patio | Screened porches, decks, patios | Black, orange |
| the-ricks-group | The Rick's Group | Hardscape + landscape management | Navy, lime, periwinkle |
| infantry-landscaping | Infantry Landscaping | Veteran-owned landscaping | Olive, white |
| leisure-time-decks | Leisure Time Decks | Decks and porches | Gold, black, white |
| wisescapes | Wisescapes | Landscape design (Cumming) | Teal, cream, forest green |
| forever-outdoors | Forever Outdoors | Decks, porches, outdoor living | Navy, steel blue |
| rc-pro-solutions | RC Pro Solutions | Hardscape + landscaping | Black, white |
| the-dreamscapes | The Dreamscapes | Design, build, maintain landscapes | Teal, blue, yellow |
| itm-landscape | ITM Landscape | Lawn care + landscape (Gwinnett) | Lime green, white |

`_engine/` is the shared builder for everything except Arnold. Edit a client's `site.py`, then run `python3 site.py` in its folder.
