# Surface brief: The $20 Auction game app

Scope: whole single-page game (home/mode picker, setup, auction stage, host panel, player dashboards, results/vote/gallery). Visitor mode: Experience (the family is inside the game).

Audience/job: a family around one shared device; host runs controls, everyone watches the stage. Constraints: rules readable in one minute, money numbers huge, creation visibly grows each win.

## Direction contract

THESIS: The game is a living Saturday comic. Each auction is a panel, each win a "SOLD!" splash page, each player's creation their own comic panel that fills in. Refuses the game-show stage with marquee bulbs and the generic dark-mode dashboard of cards.

OWN-WORLD: Process-yellow page drenched in orange Ben-Day halftone dots (chosen over newsprint white during build for party-night energy), white panels, 3px ink-black panel borders with slight panel tilt, process primaries (cyan, magenta, yellow, ink black) as flat fills; lettering in a comic display face, captions in yellow caption boxes, bids in speech balloons, sound-effect starbursts for wins. Money set in heavy condensed numerals on cash-green price tags.

STORY: The family sees one item spotlighted, shouts bids, sees balloons stack up, hears the gavel, watches SOLD! slam down and the winner's panel redraw with the new feature. At the end they compare panels side by side and vote.

FIRST VIEWPORT: Home: giant title lettering in a splash panel, a "How to play" four-panel strip, then the 30 mode covers as comic issue covers grouped in three shelves. Primary action: pick a cover.

FORM: Comic book / Sunday funnies, candidate 6 of 7 grounded list, seed key 9abce382 (degraded roll, no challengers).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
